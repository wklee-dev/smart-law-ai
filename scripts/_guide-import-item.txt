1. 개요
CAS DB 수입품목마스터(MST_CD_MNG)를 조회합니다. 거래처코드만으로 전체 조회하거나, 품목마스터코드를 추가해 단건/특정 품목을 조회합니다.
인증: CAS ID/PW 로그인 후 Bearer만 허용 (X-API-Key 불가). 호출 시 GATEWAY_API_AUDIT_LOG에 전 항목이 기록됩니다.

부록 A. Cursor 요청문 템플릿
아래를 그대로 복사해 Cursor에 붙여넣으세요.
첨부 가이드(CAS_수입품목마스터_API_Guide V1.1.docx)를 참고하여 수입품목마스터 조회 연동 프로그램을 만들어 주세요.## Gateway- 운영: https://gateway.hjcustoms.co.kr:8444- 로컬: http://127.0.0.1:5050- 호출 앱 .env (필수): CAS_GATEWAY_BASE_URL=https://gateway.hjcustoms.co.kr:8444## 필수 규칙1) CAS 로그인만 사용. API Key(X-API-Key) 사용 금지.2) POST /api/auth/login → token 저장 → Authorization: Bearer {token}3) 조회: GET /api/cas/masterSearchQry?custCd=거래처코드   선택: &amp;mstCd=품목마스터코드 (없으면 해당 거래처 전체)4) 응답은 XML만. 루트: masterSearchQryRtnVo / 행: masterSearchQryVo5) 필드명은 camelCase. DB 값이 없으면 XML 요소 없음.6) 401이면 자동 재로그인.7) CAS 비밀번호·token을 소스/README에 평문 저장하지 말 것.## 사용자 UI- [로그인] CAS userId / password- 조회: 거래처코드(custCd) 필수, 품목코드(mstCd) 선택- [조회] → 결과 그리드 (가이드 5.1 XML 요소명 기준)## API 호출1) POST /api/auth/login  Body: { "userId":"...","password":"..." }2) GET /api/cas/masterSearchQry?custCd=0736   Header: Authorization: Bearer {token}, Accept: application/xml3) XML 파싱: tCnt, masterSearchQryVo 반복## 산출물- 실행 가능한 프로그램- README (URL, 로그인·조회 방법)- .env.example (CAS_GATEWAY_BASE_URL만, 비밀값 제외)

• API Key 사용 금지. CAS 로그인만.
• CAS_GATEWAY_BASE_URL 미설정 시 로그인 실패.
• 비밀번호·token을 가이드/대화에 올리지 말 것.
