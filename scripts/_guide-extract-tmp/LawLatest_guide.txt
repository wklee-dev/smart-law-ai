K열 OR 검색 · 일반 대상 기본 70페이지 · 한시·위헌 전페이지
CSV·가상환경·DB 백업 없음
1. 처음 한 번만 설치
1. Python 3.10 이상을 설치합니다. 이미 설치되어 있으면 생략합니다.
2. ZIP을 C:\LawCrawler처럼 짧은 폴더에 풉니다.
3. install.bat을 한 번 실행합니다. 가상환경은 만들지 않습니다.
이후에는 아래에서 원하는 BAT 파일만 실행하면 됩니다.
2. 수집대상별로 한 번에 받기 — 가장 쉬운 방법
아래 BAT를 실행하면 엑셀 K열 검색 → 지정한 페이지 범위 조회 → 목록·본문·부칙·별표·첨부파일 저장을 한 번에 처리합니다. 시작페이지를 입력할 필요 없이 항상 1페이지부터 조회합니다.

“전부”는 조회한 범위에서 K열 검색어 중 하나라도 해당하는 법령 전부입니다. 사이트 전체 자료를 조건 없이 받는다는 뜻은 아닙니다. 검색 URL 길이 때문에 여러 OR 묶음으로 나누더라도, 한 번 실행하면 모든 묶음의 해당 페이지 범위를 처리합니다.
3. 메뉴를 쓰고 싶으면 run.bat
메뉴
하는 일
1. 목록만 저장
K열로 검색하여 목록만 DB에 저장합니다. 본문·부칙·별표·첨부파일은 받지 않습니다. CSV도 만들지 않습니다.
2. 한 번에 모두 수집
K열로 검색하여 목록·본문·부칙·별표·제공 첨부파일까지 받습니다. Enter를 누르면 기본으로 2번이 선택됩니다.
3. 저장목록에서 선택 수집
저장한 목록을 화면에 보여 줍니다. 화면번호를 입력하면 해당 법령의 상세·파일을 받습니다. 전체는 ALL을 입력합니다.
4. 저장목록 보기
DB 목록만 화면에 보여 줍니다. 검색과 다운로드는 하지 않습니다.
1번·2번을 선택하면 수집대상 번호를 묻습니다. 0 또는 Enter는 전체, 1 공포, 2 시행, 3 예정, 4 폐지, 5 한시법령, 6 한시조문, 7 위헌입니다. 여러 대상은 1,2처럼 입력합니다.
이어서 엑셀 gubun 번호를 묻습니다. 그냥 Enter를 누르면 K열 전체를 사용합니다. 일부 행만 원할 때는 엑셀 A열의 번호를 1-3처럼 입력합니다. A열은 선택번호·연결정보이며, 검색어는 항상 K열입니다.
그다음 종료페이지 [70]를 묻습니다. Enter는 70, 20을 입력하면 1~20페이지입니다. 한시법령·한시조문·위헌조문만 선택하면 종료페이지를 묻지 않습니다. 일반 대상과 예외 대상을 함께 선택하면 입력한 종료페이지는 일반 대상에만 적용됩니다. 3번·4번 메뉴는 저장목록을 사용하므로 종료페이지를 묻지 않습니다.
4. 검색 기준은 이것뿐입니다
K열 셀 전체 값을 검색어로 사용합니다. 이 엑셀의 비어 있지 않은 K열 479행을 읽습니다.
OR 조건: K열 값 중 하나라도 결과 법령명에 포함되면 수집합니다. 공백·가운뎃점 표기 차이는 맞춰 비교합니다.
F열 키워드와 AND 조건은 사용하지 않습니다. D열·E열 값으로 K열 검색대상을 제외하지도 않습니다.
같은 결과가 여러 검색에서 나와도 같은 법령 버전은 한 번만 수집합니다. 같은 법령의 다른 시행일자는 별도 자료로 저장합니다.
현재 수집화면은 위 최신법령 7개입니다. 행정규칙 이름도 K열 값이면 검색에 사용하지만, 행정규칙 전용 화면의 수집 기능은 이번 프로그램에 없습니다.

6. 완료·오류 메시지
종료코드 0: 지정한 범위 완료. 기본 70페이지 또는 지정한 종료페이지에서 끝나는 것은 오류가 아닙니다.
종료코드 1: 설정·DB 등 실행 오류. 화면과 logs에서 원인을 확인합니다.
종료코드 2: 일부 검색·상세·파일 실패 또는 파일형식 경고. 저장된 자료는 유지됩니다.
사이트가 HWPX 링크에서 실제 HWP 파일을 보내면 .hwp로 저장하고 경고합니다. 받은 파일은 보존합니다.
전체 수집은 시간이 걸릴 수 있습니다. 창을 닫지 말고 완료를 기다리세요. DB가 잠기면 해당 DB를 쓰는 다른 프로그램을 닫고 재실행합니다.

gubun 조회 예시
gubun은 단일 숫자가 아니라 정수 JSON 배열입니다. 복수 엑셀 행이 같은 법령에 연결될 수 있습니다. gubun 열 인덱스는 배열 전체 문자열의 직접 비교에 적용되며, 개별 숫자 검색에는 SQLite JSON1의 json_each를 사용합니다.
SELECT l.key, l.title, l.gubun
FROM llc_v1_list AS l
WHERE EXISTS (SELECT 1 FROM json_each(l.gubun) WHERE value = 1);
JSON1이 제공되지 않는 구형 SQLite에서는 Python에서 JSON을 읽어 필터링합니다. 원문 상세 조회는 각 raw 테이블의 item_key로 목록과 조인합니다.
