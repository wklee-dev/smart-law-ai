1. 개요
엔컴환급 DB 수입원장(wonjang1·wonjang2)을 조회합니다. 거래처코드만 필수이며, 원장번호·신고번호·수리일·근거서류·HS는 선택입니다. 년도(yy) 조건은 사용하지 않습니다.
인증: CAS ID/PW 로그인 후 Bearer만 허용 (X-API-Key 불가). 호출 시 GATEWAY_API_AUDIT_LOG에 전 항목이 기록됩니다.

부록 A. Cursor 요청문 템플릿
아래를 그대로 복사해 Cursor에 붙여넣으세요.
첨부 가이드(CAS_환급수입원장_API_Guide V1.0.docx)를 참고하여 환급 수입원장 조회 연동 프로그램을 만들어 주세요.## Gateway- 운영: https://gateway.hjcustoms.co.kr:8444- 로컬: http://127.0.0.1:5050- 호출 앱 .env (필수): CAS_GATEWAY_BASE_URL=https://gateway.hjcustoms.co.kr:8444## 필수 규칙1) CAS 로그인만 사용. API Key(X-API-Key) 사용 금지.2) POST /api/auth/login → token 저장 → Authorization: Bearer {token}3) 조회: GET /api/cas/ndrawSearchWanjangQry?custCd=거래처코드   선택: &amp;srlNo=원장번호 &amp;impSingoNo=수입신고번호         &amp;fromDt=YYYYMMDD&amp;toDt=YYYYMMDD (수리일 구간, 둘 다 필요)         &amp;lcNo=근거서류번호 &amp;hsCd=HS (또는 &amp;hs=)   ※ 년도(yy) 조건 없음.4) 응답은 XML만. 계층 구조:   루트: ndrawSearchWanjangQryRtnVo   마스터(원장1): ndrawSearchWanjangQryVo   상세(원장2): ndrawSearchWanjang2Vo (마스터 하위에 반복)5) tCnt = 마스터(원장1) 건수. 무결과 시 ntceInfo=결과값 없음, tCnt=06) 필드명은 camelCase. DB 값이 없으면 XML 요소 없음.7) 401이면 자동 재로그인.8) CAS 비밀번호·token을 소스/README에 평문 저장하지 말 것.## 사용자 UI- [로그인] CAS userId / password- 조회: 거래처코드(custCd) 필수  선택: 원장번호, 수입신고번호, 수리일 From~To, 근거서류번호, HS- [조회] → 마스터/상세(자재) 그리드 (가이드 5.1·5.2 XML 요소명 기준)## API 호출1) POST /api/auth/login  Body: { "userId":"...","password":"..." }2) GET /api/cas/ndrawSearchWanjangQry?custCd=999T   Header: Authorization: Bearer {token}, Accept: application/xml3) XML 파싱: tCnt, ndrawSearchWanjangQryVo 반복 → 하위 ndrawSearchWanjang2Vo## 산출물- 실행 가능한 프로그램- README (URL, 로그인·조회 방법)- .env.example (CAS_GATEWAY_BASE_URL만, 비밀값 제외)
