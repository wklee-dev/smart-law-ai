# 5개 대상 수집 후 60초 뒤 PC 종료

이 ZIP은 기존 프로그램 전체가 아니라 **BAT 교체 파일 6개**입니다. 2026-10-19 검색 오류 수정본에 적용하세요.

## 적용·실행

1. ZIP 안의 BAT 6개를 기존 크롤러의 `crawler.py`와 `config.json`이 있는 폴더에 복사합니다. 같은 이름의 BAT 5개는 덮어씁니다. DB나 파이썬 소스는 교체하지 않습니다.
2. 다른 프로그램에서 작업 중인 파일을 먼저 저장합니다.
3. **`run_five_and_shutdown.bat`만 실행**합니다.

아래 순서대로 하나씩 끝날 때까지 기다렸다가 다음 BAT를 실행합니다. 공포법령·시행법령은 실행하지 않습니다.

1. `crawl_scheduled.bat`: 시행예정법령, K열 검색어별 **1~20페이지**.
2. `crawl_repealed.bat`: 폐지법령, K열 검색어별 **1~20페이지**.
3. `crawl_temporary.bat`: 한시법령, **모든 페이지**.
4. `crawl_temporary_articles.bat`: 한시조문, **모든 페이지**.
5. `crawl_unconstitutional.bat`: 위헌조문, **모든 페이지**.

실제 검색 결과가 20페이지보다 적으면 그 마지막 페이지에서 종료합니다. 시행예정·폐지 BAT는 끝에 `--end-page 20`을 지정하므로 일반 `config.json`의 70페이지 설정보다 우선합니다. 세 예외 대상은 종료페이지 설정과 관계없이 모든 페이지를 조회합니다. 기존 K열 단일 검색·OR 합집합, 목록·본문·부칙·별표·첨부파일 저장 조건은 유지합니다.

5개 BAT가 모두 끝나면 Windows에 **60초 뒤 종료**를 요청합니다. 크롤러 실행 시작으로부터 60초가 아닙니다. 묶음 실행에서는 중간 `pause`를 건너뛰므로 키를 누르지 않아도 다음 대상이 실행됩니다. 각 BAT를 따로 실행할 때는 기존처럼 결과 화면에서 일시정지합니다.

## 주의·종료 취소

**예약 종료는 저장하지 않은 작업을 잃게 할 수 있습니다. 실행 전에 작업을 저장하세요.** Windows의 `/s /t 60` 예약 종료는 앱을 강제로 닫을 수 있습니다. Windows 권한이나 종료 취소에 따라 실제 PC 종료 여부는 달라질 수 있습니다.

**개별 수집에 오류나 0건·파일형식 경고가 있어도** 다음 BAT를 계속 실행하고, 다섯 번째 BAT가 끝난 뒤 종료를 예약합니다. 수집이 끝나기 전에 창을 닫거나 Ctrl+C로 전체 BAT 실행을 중단하면 이후 작업과 종료 예약까지 도달하지 않습니다. 시작 시 필수 파일·Python·패키지 점검에 실패하면 종료를 예약하지 않습니다. 최종 종료코드 0은 Windows가 종료 예약을 받아들였다는 의미이며, 모든 수집 성공을 의미하지는 않습니다. 각 작업의 결과와 기존 `logs`를 확인하세요.

**60초 카운트다운이 시작된 뒤 취소하려면** 다른 명령 프롬프트 또는 Win+R에서 다음을 실행합니다.

```bat
shutdown /a
```

가상환경·DB 백업·CSV 기능을 추가하지 않았습니다. DB·다운로드 경로와 Windows 긴 경로 처리는 기존 크롤러 구현을 유지합니다.

## 검증 범위

파일의 Windows CRLF 줄바꿈, ASCII 인코딩, 다섯 BAT의 순서·동기 `call`, 중간 일시정지 생략, 두 대상의 고정 종료페이지 20, 세 예외 대상의 기존 명령 유지, 모든 대상 종료 후에만 `shutdown /s /t 60`이 실행되는 구조를 정적으로 확인했습니다. 이 환경은 Linux 샌드박스이므로 Windows CMD 실제 실행이나 PC 종료를 테스트하지 않았습니다. 실제 PC에 종료 명령을 실행한 상태도 아닙니다.
