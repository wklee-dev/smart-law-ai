# 유니패스 전자등기 우편발송 목록 크롤러

이 패키지는 유니패스 전자등기 우편발송 목록을 주차 단위로 조회하여 SQLite DB에 저장하고, **품목분류회신서**의 PDF와 추출 본문을 보관합니다.

## 개선 사항

이번 버전은 로그인 후 비밀번호 변경 안내 팝업을 자동 처리하고, 팝업 처리와 무관하게 전자등기 우편발송 목록 메뉴로 직접 진입합니다. PDF는 Chrome 내장 뷰어에 띄우지 않고 파일로 바로 다운로드하므로 PDF 뷰어 제어 탐색으로 멈추지 않습니다. 자세한 내용은 [`수정내역.md`](수정내역.md)를 참고하십시오.

## 설치

Python 3.10 이상을 권장합니다. 압축을 푼 폴더에서 다음 명령을 실행합니다.

```bash
pip install -r requirements.txt
```

`env.example`을 `.env`로 복사한 뒤 실제 유니패스 로그인 정보와 DB 경로를 입력합니다. `.env`는 개인정보가 포함되므로 다른 사람에게 보내거나 버전 관리에 올리지 마십시오.

```bash
# Windows PowerShell
Copy-Item env.example .env

# macOS / Linux
cp env.example .env
```

## 실행

예를 들어 2026년 10주차를 수집하려면 다음과 같이 실행합니다.

```bash
python unipass_post_crawler.py --year 2026 --week 10
```

브라우저 창을 표시하지 않으려면 `--headless` 옵션을 추가합니다. 처음 적용할 때에는 팝업 및 화면 진입 상태를 확인할 수 있도록 일반 모드 실행을 권장합니다.

```bash
python unipass_post_crawler.py --year 2026 --week 10 --headless
```

PDF는 기본적으로 `downloads/전자등기우편발송목록/`에, 실행 로그는 `logs/`에 생성됩니다. 다른 저장 경로를 사용하려면 `--download-dir`, `--logdir`, `--db` 옵션을 지정할 수 있습니다.

## 저장 구조

| 대상 | 내용 |
| --- | --- |
| `post_list` | 조회된 전자등기 우편발송 목록 전체 이력 |
| `post_detail` | 품목분류회신서의 전자등기우편번호, PDF 절대 경로, 추출 본문 |
| `downloads/전자등기우편발송목록/` | 품목분류회신서 PDF 파일 |

기존 DB의 `post_detail` 테이블에 `전자등기우편번호`, `pdf_경로`, `본문내용` 컬럼이 빠져 있어도 프로그램 시작 시 자동으로 추가합니다.
