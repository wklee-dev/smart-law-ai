# 유니패스 전자등기 우편발송 목록 크롤러 수정내역

## 적용한 장애 조치

| 증상 | 확인한 원인 | 적용한 수정 |
| --- | --- | --- |
| 첨부 PDF 처리 중 멈춤 | Chrome 내장 PDF 뷰어 탭을 열고, 존재하지 않는 다음 페이지/다운로드 제어를 암묵적 대기와 함께 반복 탐색했습니다. 문서 1건마다 장시간 정지하고, 반복 시 브라우저 렌더러가 종료될 수 있었습니다. | Chrome PDF 뷰어를 비활성화하여 파일을 바로 다운로드합니다. 새 PDF가 완전히 저장될 때만 최대 45초 동안 대기하고, 완료·실패 뒤에는 남은 PDF 탭을 닫은 후 다음 문서로 진행합니다. PDF는 `downloads/전자등기우편발송목록/`에 저장됩니다. |
| 비밀번호 변경 팝업의 X 미클릭 | 사이트 개편에 따라 X의 고정 셀렉터를 전제로 할 수 없고, 안내 레이어가 화면을 덮을 수 있습니다. | 안내 문구를 기준으로 닫기 제어를 찾아 JavaScript로 클릭합니다. 제어를 찾지 못하면 해당 안내 레이어와 차단 오버레이만 비표시 처리합니다. 팝업 해제 실패 시에도 다음 단계가 중단되지 않습니다. |
| 사이트맵 클릭이 오래 걸림 | GNB 및 사이트맵의 여러 후보 셀렉터를 각각 최대 5~8초씩 기다렸습니다. 또한 현재 화면에서 전자등기 우편발송 목록을 직접 호출하는 함수가 아닌 경로를 우선 사용했습니다. | 로그인 후 `MYC_MNU_00011141` 메뉴를 내부 메뉴 실행 함수로 즉시 호출합니다. 사이트맵은 직접 호출 및 메뉴 ID 방식이 모두 실패할 때에만, 짧은 제한 시간으로 사용합니다. |
| 표 읽기와 다음 페이지가 느리거나 브라우저가 종료됨 | `implicitly_wait(5)` 상태에서 행마다 존재하지 않는 링크를 탐색하여 5초씩 누적됐고, 오래 보관한 Selenium 행 요소가 동적 렌더링으로 stale 상태가 됐습니다. | 전역 암묵적 대기를 0으로 바꾸고, 표를 JavaScript 스냅샷으로 한 번에 읽습니다. 문서 링크는 클릭 직전에 현재 표에서 다시 찾아 stale 요소를 보관하지 않습니다. |
| 기존 DB에서 `전자등기우편번호` 컬럼 오류 | 이미 생성된 `post_detail` 테이블은 `CREATE TABLE IF NOT EXISTS`만으로 새 컬럼이 추가되지 않았습니다. | 시작 시 `PRAGMA table_info`로 기존 스키마를 점검하고, 누락된 `전자등기우편번호`, `pdf_경로`, `본문내용` 컬럼을 자동 추가합니다. |

## 설치 및 실행

`env.example`을 `.env`로 복사한 뒤, `.env`에 유니패스 ID와 비밀번호를 입력합니다. 템플릿과 프로그램 소스에는 로그인 정보를 저장하지 않습니다.

```bash
pip install -r requirements.txt
python unipass_post_crawler.py --year 2026 --week 10
```

브라우저를 숨기려면 다음처럼 실행할 수 있습니다. 최초 확인 때에는 일반 모드로 실행해 팝업과 로그를 함께 확인하는 편이 좋습니다.

```bash
python unipass_post_crawler.py --year 2026 --week 10 --headless
```

## 결과 확인

목록 이력은 `post_list`, PDF 경로와 추출 본문은 `post_detail`에 저장됩니다. PDF는 기본적으로 `downloads/전자등기우편발송목록/`에 분리 저장됩니다. 개별 PDF가 45초 이내에 저장되지 않으면 해당 문서만 경고 로그를 남기고 다음 문서로 넘어가므로 전체 실행이 무기한 멈추지 않습니다.
