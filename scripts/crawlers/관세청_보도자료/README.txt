관세청 보도자료 크롤러 V1.0

자세한 설치, 실행, SQLite 테이블 명세는 동봉한 Word 사용가이드를 참조하세요.

[설치]
1. Windows에 Python 3.9 이상과 pip를 설치하고 Python 명령을 사용할 수 있게 설정합니다.
2. 기존 D:\SQLiteDB\smart_law_ai.db를 백업하고 파일이 존재하는지 확인합니다.
3. setup.bat을 실행하여 필요한 라이브러리를 설치합니다. 가상환경은 필요하지 않습니다.

[실행 예시: 명령 프롬프트에서 이 폴더로 이동한 후]
run.bat 1                             1페이지의 목록, 본문과 첨부파일
run.bat 1 10                          1~10페이지의 목록, 본문과 첨부파일
run.bat --from 1 --to 10              1~10페이지의 목록, 본문과 첨부파일
run.bat all                           모든 페이지
run.bat 1 10 --stage list             목록만 먼저 수집
run.bat 1 10 --stage detail           저장된 1~10페이지 목록의 상세와 첨부파일 수집
run.bat all --stage detail            DB에 저장된 모든 목록의 상세와 첨부파일 수집
run.bat                               config.ini에 설정된 범위로 수집(기본 1페이지)

기본 DB: D:\SQLiteDB\smart_law_ai.db
첨부파일: D:\SQLiteDB\downloads\관세청\보도자료\게시물ID\
로그: 프로그램 폴더의 logs\YYYY-MM-DD.log

DB가 없다면 기본적으로 새로 만들지 않고 중단합니다. DB의 위치를 확인하세요.
새 DB 생성이 꼭 필요할 경우에만 --create-db 옵션을 사용하세요.
수집 실패 시 로그를 확인하고 같은 범위를 다시 실행하세요. 재실행 시 첨부를 다시 받습니다.
첨부파일의 게시판 표시 크기와 실제 수신 크기가 다르면 파일은 저장하고 확인 필요로 기록합니다.
이 경우 재실행 후에도 차이가 계속될 수 있으므로 저장된 파일을 직접 확인하세요.
사이트에 신규 글이 게시되면 페이지가 밀릴 수 있으므로 수집 후 범위를 다시 확인하세요.
프로그램 파일은 Python 스크립트이며 독립 실행형 EXE는 아닙니다.
