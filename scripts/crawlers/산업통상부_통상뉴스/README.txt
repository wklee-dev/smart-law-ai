산업통상부 FTA 통상뉴스(주요동향) 크롤러 V1.1

자세한 사용법, DB 테이블 상세, 문제 해결은 guide.docx를 참고하세요.

1. 압축을 풀고 Python 3.9 이상 및 pip를 설치합니다. 가상환경은 필요하지 않습니다.
2. install.bat을 실행하여 requests와 beautifulsoup4를 설치합니다.
3. config.ini의 DB 및 다운로드 경로를 확인합니다. 기본 DB는 이미 존재해야 합니다.
4. run.bat을 실행하고 수집할 페이지를 입력합니다.

  입력: 1       1페이지만 수집
  입력: 2 5     2~5페이지 수집
  입력: 2~5     2~5페이지 수집
  입력: all     전체 페이지 수집
  입력 없이 Enter: config.ini의 기본 범위 사용 (기본 1~1페이지)

명령 프롬프트 예시:
  python fta_crawler.py 1
  python fta_crawler.py 2 5
  python fta_crawler.py --from 2 --to 5
  python fta_crawler.py all
  python fta_crawler.py

주차나 날짜 필터 없이 선택한 페이지의 모든 게시글을 수집합니다.
all은 마지막 페이지까지 수집하므로 시간이 오래 걸릴 수 있습니다.
기존 DB는 실행 전 백업을 권장합니다.

기본 다운로드: D:\SQLiteDB\downloads\산업통상부\통상뉴스\게시글ID\
로그: 프로그램 폴더의 logs\YYYY-MM-DD.log
실패 항목이 있으면 0이 아닌 종료코드로 표시됩니다. 같은 범위를 다시 실행하면
실패한 다운로드를 재시도하며, 이미 저장된 기사/파일이 중복 생성되지 않습니다.
본문 HTML의 이미지 링크는 원본을 유지하고, 이미지 파일은 별도 저장합니다.
직접 주소형 첨부를 지원하지만 실제 포털 표본에서는 별도 첨부가 발견되지 않아
실제 첨부 다운로드는 검증하지 못했습니다. 미지원 스크립트 첨부가 감지되면
오류로 기록합니다. 외부 서버 접근이 막히거나 사이트 구조가 바뀔 수 있습니다.
