# 관세청 행정규칙 행정예고 크롤러 v3.1

> 관세청 행정예고 게시판의 공고 목록, 본문(HTML/텍스트), 첨부파일을 완전 자동 다운로드합니다.
> **기존의 선택형 메뉴를 모두 없애고, 시작페이지와 종료페이지만 지정하면 즉시 자동 수집됩니다.**

---

## 1. 사용 방법 (시작페이지 ~ 종료페이지 지정)

### 방법 A. 실행 후 시작/종료페이지만 입력 (가장 추천)

**`run_crawler.bat`** 를 더블클릭합니다.

```
시작 페이지 (Enter=1) : 1
종료 페이지 (Enter=시작페이지) : 5
```

- **그냥 Enter 두 번** 치면 **1페이지만 자동 수집**됩니다.
- `1` 입력 후 `5` 입력하면 **1~5페이지(50건) 자동 수집**됩니다.
- 복잡한 메뉴 번호 선택이 전혀 없습니다.

### 방법 B. 명령줄에서 시작/종료페이지를 뒤에 붙여 실행

```bat
run_crawler.bat 1           :: 1페이지만 자동 수집
run_crawler.bat 1 5         :: 1~5페이지 자동 수집
run_crawler.bat all         :: 전체 페이지 자동 수집

:: 또는 python 명령으로 직접 실행:
python customs_crawler.py 1 5
```

### 방법 C. 아무것도 묻지 않고 완전 자동 (config.ini 설정)

`config.ini` 파일을 메모장으로 열어 시작/종료페이지를 적어두면,
**`run_auto.bat` 더블클릭만으로 즉시 자동 수집**됩니다 (입력 창조차 안 뜹니다).

```ini
[crawler]
start_page = 1
end_page = 5
```

## 2. 배치 파일 목록

| 파일 | 설명 |
|---|---|
| `install.bat` | 필수 라이브러리 1클릭 설치 (최초 1회) |
| **`run_crawler.bat`** | **[메인] 시작/종료페이지 지정 자동 수집** (인자 전달도 가능) |
| `run_auto.bat` | config.ini 설정대로 무입력 즉시 자동 수집 |
| `run_page1.bat` | 1페이지 전용 원클릭 자동 수집 |
| `run_all.bat` | 전체 페이지 전용 원클릭 자동 수집 |
| `run_stage1.bat` | 1단계(목록만) 수집 |
| `run_stage2.bat` | 2단계(미수집 본문/첨부) 자동 완료 (중단 후 이어받기) |
| `retry_failed.bat` | 실패한 첨부파일만 재다운로드 |
| `view_status.bat` | DB 수집 현황 통계 조회 |

## 3. 핵심 규칙

- **전건 수집**: 폐지제정 등 모든 공고를 조건 없이 100% 수집
- **DB**: `D:\SQLiteDB\smart_law_ai.db` (전용 테이블명 사용으로 기존 데이터와 공존)
- **첨부파일**: `D:\SQLiteDB\downloads\관세청\행정규칙예고` 폴더에 `공고번호_원본파일명` 형태로 충돌 없이 저장
- **로그**: `logs\YYYY-MM-DD.log`
- **중단 후 재개**: 언제든 `run_stage2.bat`를 실행하면 미수집 건만 이어받기 완료
