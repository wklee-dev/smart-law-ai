# 유니패스 분석진행사항 크롤링 프로그램 v14

유니패스(unipass.customs.go.kr)의 **분석진행사항** 메뉴에서 진행상태가 **'분석실 완료'**인 건의 **분석결과안내문** 데이터를 자동으로 수집하여 엑셀 및 SQLite DB에 저장합니다.

**v13 신규 기능**: 공인인증서 로그인 자동화 (pywinauto 기반)

---

## 파일 구조

```
unipass_crawler/
├── main.py                  # 메인 실행 파일
├── crawler.py               # 크롤링 핵심 로직
├── session_manager.py       # 세션 관리 (공인인증서 자동화 포함)
├── saver.py                 # 결과 저장 (엑셀 + SQLite)
├── config.json              # 설정 파일 (인증서 정보 포함)
├── customs_ids.xlsx         # 통관고유부호 입력 파일 (직접 편집)
└── output/                  # 결과 저장 폴더 (자동 생성)
    └── 분석결과_크롤링.xlsx
```

---

## 사전 준비

### 1. 패키지 설치

```bash
pip install selenium beautifulsoup4 openpyxl pandas pywinauto
```

> **pywinauto**: 공인인증서 팝업 자동화에 필요합니다. Windows 전용 패키지입니다.

### 2. Chrome 드라이버 설치

- Chrome 브라우저와 동일한 버전의 [ChromeDriver](https://chromedriver.chromium.org/)를 설치합니다.
- PATH에 등록하거나 `chromedriver.exe`를 프로그램 폴더에 복사합니다.

### 3. MagicLine4NX 설치

- 유니패스 공인인증서 로그인에 필요한 MagicLine4NX 보안 프로그램이 설치되어 있어야 합니다.
- 유니패스 로그인 페이지에서 설치 안내를 따르세요.

## 공인인증서 자동화 설정 (v13 신규)

### config.json 설정

```json
{
  "accounts": [
    {
      "certificate": {
        "alias": "한국무역정보통신",
        "password": "인증서_비밀번호"
      }
    }
  ]
}
```

| 항목 | 설명 | 예시 |
|------|------|------|
| `alias` | 인증서 선택 창에 표시되는 인증서 이름 (일부만 입력해도 됨) | `"한국무역정보통신"` |
| `password` | 공인인증서 비밀번호 | `"mypassword123"` |

- `alias`와 `password` 중 하나라도 입력되면 **자동화 모드**로 동작합니다.
- 두 항목 모두 비워두면 **수동 로그인 대기 모드**로 동작합니다 (기존 방식).

### 자동화 동작 순서

```
1. 유니패스 로그인 페이지 열기
2. 공인인증서 로그인 버튼 자동 클릭
3. MagicLine4NX 인증서 선택 창 팝업 감지
4. alias에 해당하는 인증서 자동 선택 → 확인 클릭
5. 비밀번호 입력 창 팝업 감지
6. 비밀번호 자동 입력 → 확인 클릭
7. MagicLineSession 쿠키 확인 → 로그인 완료 감지
8. 크롤링 자동 시작
```

### 보안 주의사항

> `config.json`에 인증서 비밀번호가 **평문으로 저장**됩니다.
> 파일 접근 권한을 제한하거나 공유 폴더에 두지 마세요.

## 실행 방법

### 기본 실행

```bash
python main.py
```

**자동화 모드** (config.json에 인증서 정보 설정 시):
1. 브라우저가 자동으로 열립니다.
2. 공인인증서 로그인 버튼이 자동으로 클릭됩니다.
3. 인증서 선택 창과 비밀번호 창이 자동으로 처리됩니다.
4. 로그인 완료 후 크롤링이 자동으로 시작됩니다.

**수동 모드** (인증서 정보 미설정 시):
1. 브라우저가 자동으로 열립니다.
2. 사용자가 직접 공인인증서 로그인을 완료합니다.
3. 로그인 감지 후 크롤링이 자동으로 시작됩니다.

### 옵션

```bash
# 특정 통관고유부호만 처리
python main.py --customs-id 한국쓰리엠1771019

# 페이지당 50건씩 조회 (기본: 10건)
python main.py --page-size 50

# 3~10페이지만 수집
python main.py --page-range 3-10

# 1, 3, 7페이지만 수집
python main.py --pages 1,3,7

# DB 전체 데이터를 엑셀로 내보내기
python main.py --export-db

# 디버그 모드 (HTML을 debug_output/ 폴더에 저장)
python main.py --debug
```

### 페이지 선택 수집 (v14 신규)

- 옵션을 생략하면 기존처럼 **1페이지부터 마지막 페이지까지** 모두 수집합니다.
- `--page-range FROM-TO`는 연속한 페이지 범위만 수집합니다. 예: `python main.py --page-range 3-10`
- `--pages PAGE[,PAGE...]`는 필요한 페이지만 수집합니다. 예: `python main.py --pages 1,3,7`
- 두 옵션은 동시에 사용할 수 없습니다. 입력한 페이지가 실제 전체 페이지 수를 초과하면 해당 통관고유부호의 수집을 중단하고 오류를 기록합니다.
- 페이지 선택은 처리 대상인 모든 통관고유부호에 적용됩니다.

자세한 사용법, 입력 규칙 및 오류 처리 예시는 [페이지 선택 크롤링 사용 안내](페이지_선택_크롤링_사용안내.md)를 참조하세요.

## 문제 해결

### 인증서 선택 창에서 인증서를 찾지 못하는 경우

`config.json`의 `alias` 값을 인증서 창에 표시되는 이름의 일부로 수정하세요.
alias를 빈 문자열로 두면 첫 번째 인증서가 자동 선택됩니다.

```json
"alias": ""
```

### 비밀번호 입력이 안 되는 경우

비밀번호에 특수문자가 포함된 경우 일부 문자가 제대로 입력되지 않을 수 있습니다.
이 경우 로그 파일(`logs/` 폴더)을 확인하고, 수동 모드로 전환하여 사용하세요.

### DB 경로 오류 (Windows)

`config.json`의 `db_path`에 Windows 경로를 지정할 때 역슬래시를 이중으로 입력하세요:
```json
"db_path": "D:\\SQLiteDB\\unipass_bunsuk.db"
```

### pywinauto 설치 오류

```bash
pip install pywinauto
```

pywinauto는 **Windows 전용** 패키지입니다. Linux/Mac에서는 설치되지 않습니다.
