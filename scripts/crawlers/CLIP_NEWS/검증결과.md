# 행정예고 크롤러 V1.3 검증 결과

확인일: 2026-10-15.

## 이번 변경 범위

- 페이지를 실행 파라미터 `--pages`로만 받도록 run.bat의 대화형 분기를 제거했습니다.
- 페이지 파라미터가 없으면 구버전 config.json의 pages 값과 관계없이 전체 페이지를 선택합니다.
- 모든 BAT 파일의 pause를 제거했습니다. 정상/오류 후 입력 대기 없이 기존 종료코드를 반환합니다.
- 대화형 입력 전용 select_pages.py는 새 배포본에서 제외했습니다.
- 그 외 크롤링·첨부 다운로드·DB·백업·증분 저장·진행 표시 로직은 변경하지 않았습니다.

## V1.3 검증

| 항목 | 결과 |
| --- | --- |
| Python 문법 검사 | 통과 |
| 자동 테스트 | 74개 통과 |
| 페이지 파라미터 없음 | 전체 3페이지 시험 목록을 수집. input 호출 없음 |
| 구버전 설정의 pages 값 | 파라미터 미지정이면 무시하고 전체 선택 |
| --pages 2 | 선택 페이지 자료만 수집. input 호출 없음 |
| 잘못된 페이지 파라미터 | 오류로 종료. 전체로 전환하지 않음 |
| 모든 BAT | pause/set /p/choice 입력 대기 명령 없음, 대화형 선택 모듈 호출 없음 |
| 진행 표시 | 시작 안내와 비버퍼 출력 유지 |
| 기존 기능 회귀 | 선택 범위 제한, 첨부 재사용/복구, 초기 전체 완료 상태, 기존 DB 보존 등 통과 |
| DB 호환성 | schema.sql은 V1.2와 동일. schema_version=1.0 유지 |

Windows BAT 직접 실행과 사용자의 운영 DB 연결은 이 Linux 환경에서 수행하지 못했습니다. BAT의 pause 제거, 대화형 분기 제거, 파라미터 전달 및 종료코드 처리는 소스 검사로 확인했습니다. 더블클릭 실행 시 완료 후 창이 닫힐 수 있으며 열린 명령 프롬프트에서 실행하면 결과 화면을 계속 볼 수 있습니다.

## 이전 실사이트 표본 — 이번 변경에서 재수집하지 않음

V1.2에서 10건 기준 2페이지 목록 10건을 확인하고, 게시글 20260147 ‘보세사제도 운영에 관한 고시’ 상세 1건과 HWPX 첨부 3개를 정상 수집했습니다. DB 무결성·SHA256·문서 ZIP CRC 검사도 통과했습니다. --max-notices 1로 제한한 표본 시험이라 종료코드 2(partial)였습니다.

이번 V1.3은 실행 입력 방식과 pause 제거만 변경했고 실사이트 수집을 다시 수행하지 않았습니다. 전체 상세/첨부 전량 다운로드를 검증한 결과가 아닙니다.
