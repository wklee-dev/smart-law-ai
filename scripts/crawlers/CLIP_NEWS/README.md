# 관세법령정보포털 행정예고 크롤러 V1.3

**페이지는 실행 파라미터로만 지정합니다. 페이지 파라미터가 없으면 전체 페이지를 수집합니다. 실행 중 입력란이 없으며 모든 BAT의 pause를 제거했습니다.**

## 설치와 실행

1. Python 3.10 이상을 설치하고 ZIP을 일반 폴더에 압축 해제합니다.
2. 필수 라이브러리를 아직 설치하지 않았다면 `setup.bat`를 한 번 실행합니다.
3. `config.json`의 DB/첨부 경로를 확인합니다.
4. 명령 프롬프트에서 프로그램 폴더로 이동한 뒤 아래 명령으로 실행합니다.

| 수집 범위/목적 | 명령 |
| --- | --- |
| 전체 페이지 | `run.bat` |
| 2페이지만 | `run.bat --pages 2` |
| 2~4페이지 | `run.bat --pages 2-4` |
| 1, 3, 5~7페이지 | `run.bat --pages 1,3,5-7` |
| 포털 10건 표시와 맞춘 2페이지 | `run.bat --pages 2 --page-size 10` |
| 선택 페이지 본문까지 재확인 | `run.bat --pages 2-4 --full` |
| 전체 본문 재확인 | `run_full.bat` |
| 전체 파일 무결성 확인·복구 | `run.bat --verify-files` |
| 선택 페이지 파일 무결성 확인·복구 | `run.bat --pages 2 --verify-files` |

`--pages`를 생략하거나 `--pages ""`를 전달하면 전체 페이지입니다. 구버전 `config.json`의 `pages`에 값이 있어도 사용하지 않습니다. 페이지는 처음부터 명령줄 파라미터로만 지정합니다. 잘못된 파라미터나 존재하지 않는 페이지는 오류로 종료하며 전체 다운로드로 임의 전환하지 않습니다.

## BAT 종료 동작

`run.bat`, `run_full.bat`, `setup.bat`, `test.bat`, `test_live.bat`, `find_python.bat` 모두 `pause`가 없습니다. 완료/오류 후 키 입력을 기다리지 않고 종료코드를 반환합니다. `run.bat`에는 페이지를 묻는 입력 분기도 없습니다.

시작·진행 표시와 `logs` 파일 저장은 유지합니다. 더블클릭하면 종료 후 창이 닫힐 수 있으므로 진행/결과를 계속 보려면 이미 열린 명령 프롬프트에서 실행하세요.

다른 BAT에서 호출할 때는 `call run.bat --pages 2`처럼 호출하면 종료 후 다음 명령을 이어서 실행할 수 있습니다.

## 기존 규칙 유지

- 가상환경을 만들거나 사용하지 않습니다. 설치된 일반 Python을 `py -3` 또는 `python`으로 찾습니다.
- 기본 DB: `D:\SQLiteDB\smart_law_ai.db`
- 기본 첨부: `D:\SQLiteDB\downloads\행정예고\게시글ID\`
- 기본 페이지당 건수는 **100**입니다. 포털 10건 화면과 맞추려면 `--page-size 10`을 사용하세요.
- 전용 테이블 5개와 스키마 버전 1.0을 유지합니다. 기존 DB의 다른 테이블은 변경하지 않습니다.
- 기존 DB 실행 전 백업, 증분 저장, 성공 첨부 재사용, 오류 복구와 진행 표시를 유지합니다.
- 페이지 미지정은 전체 범위이며, 이미 성공한 자료는 기존 증분 규칙에 따라 재사용합니다.
- 선택 페이지 성공을 초기 전체 완료 상태로 기록하지 않습니다.

이전 config.json의 DB/첨부 경로를 그대로 사용할 수 있습니다. 필요한 라이브러리가 이미 설치되어 있으면 재설치할 필요가 없습니다. 사용자 운영 DB/첨부는 ZIP에 포함하지 않습니다. Python이 필요한 소스 실행 패키지이며 `.exe`는 아닙니다.

## Python 직접 실행

```bat
py -3 crawler.py
py -3 crawler.py --pages 2
py -3 crawler.py --pages 2-4 --page-size 10
```

`py`가 없으면 `python`으로 바꾸세요. Linux/macOS에서는 실제 로컬 DB/첨부 경로를 함께 지정해야 합니다.
