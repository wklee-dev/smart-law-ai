3. 구조적 특징 및 활용 시 유의사항
3.1 공통 레이아웃
상단 대메뉴 8종 + 통합검색 영역이 모든 화면에 고정 노출된다.
2~3개 iframe 조합 구조를 사용한다. 좌측 목차는 I1(세율·수출입요령·법령), 우측 본문은 right/detail 프레임이다.
화면 수집·재구축 시 상위 URL이 아닌 iframe 내부 URL을 직접 사용하는 것이 효율적이다.
3.2 핵심 데이터 화면
관세율표 > HS 통합조회(answer.asp?strHS={HSK})가 서비스의 핵심으로, 품목정보·관세·FTA 협정세율·감면·내국세·수출입요건을 한 화면에 제공한다.
해당 화면은 회원 전용이며, 진입 시 세션 기반 redirect.asp를 경유한다.
3.3 접속 제약
회원 아이디별 일일 접속 횟수 제한이 있어 초과 시 당일 로그인이 차단된다.
따라서 자동 수집은 1일 1회 로그인 후 단일 세션으로 전량을 처리하는 구조가 필요하다.
3.4 연도 경로
URL의 Y2025·Y2026 등은 관세율표 적용연도를 의미하며 2002년부터 동일한 구조로 제공된다.
연도 경로를 파라미터화하면 과거 연도 데이터의 시계열 비교 기능을 구현할 수 있다.
