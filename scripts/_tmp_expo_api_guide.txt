
NCOM 수출 DB 조회
ncomSearchExpoQry 호출 가이드
HanjooGatewayAPI  |  문서 버전 1.0  |  응답: XML  |  운영: https://gateway.hjcustoms.co.kr:8444
1. 개요
NCOM 수출신고 데이터(expo1 / expo2 / expo3)를 조회하여 유니패스 화물통관진행정보·수입 ncomSearchQry 와 유사한 XML로 반환합니다.
응답은 부모(expo1 공통) → 자식(expo2 란) → 손자(expo3 행) 계층 구조입니다.

5. 응답 XML 구조
&lt;?xml version="1.0" encoding="utf-8"?&gt;&lt;ncomSearchExpoQryRtnVo&gt;  &lt;ntceInfo/&gt;  &lt;tCnt&gt;1&lt;/tCnt&gt;                      &lt;!-- expo1 건수 --&gt;  &lt;ncomSearchExpoQryVo&gt;               &lt;!-- expo1 --&gt;    &lt;expoSingoNo&gt;...&lt;/expoSingoNo&gt;    &lt;!-- expo1 컬럼 camelCase --&gt;    &lt;ncomSearchExpo2Vo&gt;               &lt;!-- expo2 란 --&gt;      &lt;exlanLan&gt;...&lt;/exlanLan&gt;      &lt;ncomSearchExpo3Vo&gt;             &lt;!-- expo3 행 --&gt;        &lt;expumHaeng&gt;...&lt;/expumHaeng&gt;      &lt;/ncomSearchExpo3Vo&gt;    &lt;/ncomSearchExpo2Vo&gt;  &lt;/ncomSearchExpoQryVo&gt;&lt;/ncomSearchExpoQryRtnVo&gt;
요소
설명
ntceInfo
안내/오류. 정상 시 빈 요소
tCnt
상위(expo1) 건수. 없으면 0
ncomSearchExpoQryVo
expo1 부모
ncomSearchExpo2Vo
expo2 자식(란)
ncomSearchExpo3Vo
expo3 손자(행)
필드명은 camelCase (예: Expo_singo_no → expoSingoNo). 제외: Expo_key, Exlan_key, Expum_key, Expum_lan. 컬럼 목록·순서는 docs/수출테이블.xlsx 기준.
조회 결과 없음 (유니패스 무결과 패턴)
&lt;ncomSearchExpoQryRtnVo&gt;  &lt;ntceInfo/&gt;  &lt;tCnt&gt;0&lt;/tCnt&gt;&lt;/ncomSearchExpoQryRtnVo&gt;
파라미터 오류(400) 시에도 XML을 반환하며, 메시지는 ntceInfo에 들어갑니다.

8. 연동 시 주의사항
• 외부 연동은 반드시 운영 URL을 사용하세요. 127.0.0.1:5050 은 Gateway PC 진단용입니다.
• API Key는 소스·프론트엔드에 넣지 말고 서버 환경변수로만 관리하세요.
• Mode A 기간 조회는 XML이 커질 수 있으므로 타임아웃·메모리를 여유 있게 두세요.
• 수입 API(ncomSearchQry)와 URL·루트 요소명이 다릅니다. 혼동하지 마세요.
